# 目标与验收

目标：做一款以日常工作体验为优先级的跨平台 RDP 客户端。Flutter
负责界面；FreeRDP 固定为只读子模块；所有适配放在 LRDP 仓库内。
“超过 aRDP Free”是产品目标，不能用界面完成度替代实机对比。

## 第三阶段：与 aRDP Free 对比

在相同 Android 设备、Windows 主机、分辨率和网络条件下，对照记录：

1. 从冷启动到远程桌面可操作所需的时间与操作次数。
2. 文字编辑、代码编辑、网页滚动时输入到画面反馈的 P50/P95 延迟。
3. 1080p 空闲/滚动/视频场景下的 CPU、内存、帧率、流量和耗电。
4. 中文输入、触控拖动、右键、远程组合键、蓝牙键鼠和剪贴板成功率。
5. 断网恢复、Wi-Fi/蜂窝切换、锁屏、旋转、后台恢复和连续 8 小时使用。
6. 五个平台的安装、凭据存储、证书变化、错误反馈与可访问性。

每个结果必须附设备、系统、客户端版本、服务端配置、原始日志和复现步骤。
全部核心任务通过后再发布“优于”结论。当前版本是开发预览。
