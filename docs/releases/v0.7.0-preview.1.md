LRDP **0.7.0 开发预览**（`v0.7.0-preview.1`，Android versionCode **10**）。

本次提供 Linux x86_64 AppImage、Android ARM64 正式签名 APK、完整源码、FFmpeg / nv-codec-headers 重建资料、构建日志和 SHA-256 校验文件。安装包从本标签提交构建；原生 ABI 保持 v5，FreeRDP 3.32.2 子模块源码未修改。

## 本次变化

- **全屏由用户选择**：新连接默认非全屏，可在设置中开启“连接时全屏”，也可在会话内随时切换。桌面标签、手机会话选择及打开已有连接保留当前窗口状态，不再重新进入全屏。以前显式保存的全屏选择会保留。
- **快捷面板 Win 键**：可直接发送一次 Windows 键按下/释放，未连接时禁用；屏幕键盘的 Win 继续支持修饰键保持和组合键。
- **保存失败可直接重试**：连接编辑器等待保存成功才关闭。失败保留填写的地址、用户名、密码与选项；保存期间防止重复提交和关闭。普通编辑与 RDP 文件导入均在保存成功后才连接。
- **批量备份导入**：整批配置在写入队列中合并并一次保存，失败不发布半批结果，并发导入正确去重。账号识别包含域，修复同一服务器、用户名但不同域的配置无法读取或被跳过的问题。
- **备份大小保护**：导入和导出均限制为 8 MiB，避免一次读取过大文档；格式仍为版本 1，不含密码或证书信任。大于限制的旧备份需先拆分后导入。
- **剪贴板重连与异步保护**：去重缓存绑定会话及当前连接，重连后同文本可重新同步；手动同步允许重发相同文本。异步读取返回后复验目标、连接状态和前台状态，避免向过期连接发送；保留远端更新优先和显式图片粘贴后的缓存。
- **失焦立即停止连发**：长按按键时切到后台或窗口失焦会取消连发，恢复前台不会自行继续。

## 验证与限制

本地已通过 Flutter **337 passed / 11 skipped**、静态分析与格式检查、原生 CTest **8/8**，以及隔离 TLS 回环的正常输入释放与背压停止测试。新增 48 项 Flutter 回归（相比 0.6.0 的 289 项），覆盖窗口状态、Win 扩展扫描码、备份事务、保存重试、剪贴板连接代次与生命周期。组件测试使用模拟存储、会话或剪贴板通道，不代表真实系统验收。

发布流水线重新执行 Flutter / Python / Java host / 原生测试、签名 APK 的结构 / 主入口 / 16 KiB 校验、AppImage payload / glibc 校验和产物摘要。实际构建日志见随附的 `lrdp-0.7.0-verification.zip`。

本地完整键盘回环尝试因缺少 `Xvnc` 未能启动；快捷 Win 的真实服务端开始菜单、实际窗口全屏、系统剪贴板重连及本次安装包的交互式桌面验收仍待复验。底层输入释放测试不等同于 Flutter 长按端到端测试。ARM64 手机、厂商输入法与安全存储故障恢复也未在本批真机验收；Windows / macOS / iOS 不提供本次安装包。

沿用 0.6.0 的 Android MediaCodec H.264 实验路径：**尚未验证到真实 MediaCodec Image/JNI 成功出帧，不能承诺 CPU 或功耗下降**。API24–28 保守使用 CPU，API29+ 在硬件路径失败后回退 CPU。成功硬解、真实 AVC444 / AVC444v2、长期稳定性及各厂商设备仍待验收。详细历史记录见源码内 `docs/VERIFICATION.md`。

## 安装

Android ARM64 APK 沿用正式发布密钥，可覆盖升级此前的正式签名版本。本地开发签名包与正式包签名不同；若需卸载测试包，先导出不含密码的配置并妥善保留凭据，卸载会清除应用数据。

```sh
chmod +x lrdp-0.7.0-linux-x64.AppImage
./lrdp-0.7.0-linux-x64.AppImage
sha256sum -c SHA256SUMS
```

Linux 需要 glibc ≥ 2.35 和可用的 OpenGL / EGL；无 FUSE 时可用 `APPIMAGE_EXTRACT_AND_RUN=1`。Linux 硬解需要宿主机驱动及设备权限，不支持时回退 CPU。
