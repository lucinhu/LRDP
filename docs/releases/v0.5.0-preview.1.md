LRDP **0.5.0 开发预览**（`v0.5.0-preview.1`，Android versionCode **8**）。

本次提供 Linux x86_64 AppImage、Android ARM64 正式签名 APK，以及完整源码、FFmpeg / nv-codec-headers 重建资料、构建日志和 SHA-256 校验文件。二进制由 GitHub Actions 在 Ubuntu 22.04 上从本标签提交构建，原生 ABI 保持 v5，新增接口为可选扩展；FreeRDP 3.32.2 子模块源码未修改。

## 更新

- **Linux H.264 自动硬解**：按设备与码流支持尝试 VA-API（Intel/AMD 等）和 CUDA/NVDEC（NVIDIA）；实际解码并下载成功后才报告 GPU。设备不可用、格式不支持或运行期失败时自动回退 CPU，并重放必要参数和参考帧，避免直接从 P 帧切换造成花屏。历史有内存与包数上限，不并行双解；会话信息显示最近成功 H.264 帧的 CPU / VA-API / CUDA 后端，旧原生库显示未获取。
- **后台会话降载**：隐藏会话通过连接线程请求服务端暂停图形输出（需要服务端支持），恢复后重新绘制；降低后台控制轮询频率，并将控制查询与显示帧率分开，避免高刷新率下重复查询状态和剪贴板。桌面窗口失去焦点仍正常显示。
- **Linux / Android 快照复制限帧**：按显示帧率合并原生损坏区域、减少重复快照复制，保留首帧、尺寸变化和没有后续数据时的末帧。这不等于限制 H.264 解码或网络流量。
- **Android 静态画面降载**：API24–29 等路径不再因缺少 Surface 刷新率提示而重复执行 JNI / EGL 绘制；缓存画面尺寸，并修复呈现代数与 Surface 重建之间的竞争。
- **信息与诊断**：增加匿名的实际解码后端诊断；画质说明不再将单台机器的 CPU 或带宽结果写成固定表现。

## 验证范围

发布流水线执行 Flutter analyze / 完整测试、原生 CTest、Python 回归、Android APK 的 ABI / RELRO / ZIP 对齐 / 签名 / 主入口校验及 AppImage payload / glibc 校验，实际日志见 `lrdp-0.5.0-verification.zip` 和 `BUILD_INFO.json`。

本地实现验收已通过：原生 **6/6**、Flutter **289 passed / 11 skipped**；真实私有 TLS / RDPGFX AVC420 的 CUDA 与 CPU 路径（实际 IDR / P 帧、完整像素、输入、停止）；四类硬件故障的 CPU 参考帧恢复、历史上限和软件路径内存检查；Android API26 x86_64 模拟器真实 JNI / EGL 静态帧、Surface 重建与隐藏 / 恢复检查。上述本地报告与本次 CI 安装包验收分别记录，不作为所有显卡或手机已通过的结论。

**待验收**：VA-API 成功路径、AVC444 / AVC444v2 真实服务互操作、用户设备上的 CPU 降幅 / 耗电 / 长时间稳定性、实际 Windows RDP / KRDP 桌面及 AppImage 交互式窗口 / 输入 / 全屏验收、Android ARM64 真机和厂商驱动。本轮 Android、Windows 和 Apple 仍使用软件 H.264 解码；不提供 Windows / macOS / iOS 安装包。GPU 帧仍需下载、GDI 合成和纹理上传，不是端到端零拷贝，也不按 CPU / GPU 实测耗时选择后端。

## 安装

```sh
chmod +x lrdp-0.5.0-linux-x64.AppImage
./lrdp-0.5.0-linux-x64.AppImage
```

Linux 需要 glibc ≥ 2.35 与可用的 OpenGL / EGL。无 FUSE 时可用 `APPIMAGE_EXTRACT_AND_RUN=1` 启动。硬解还需要宿主机厂商驱动与设备访问权限；使用的 NVDEC 头文件要求 Linux NVIDIA 驱动至少 530.41.03，能否解码仍取决于显卡和码流支持。不支持时自动使用 CPU。

Android 安装 ARM64 APK，沿用 LRDP 正式发布密钥，可覆盖安装 0.4.0 正式签名包。本地调试签名或其他签名的预览包需先卸载（会清除应用数据）。升级后重新连接 H.264 会话，在会话信息中查看实际后端。

校验附件：`sha256sum -c SHA256SUMS`。构建方法、源码重建步骤与详细限制见源码内 `docs/BUILDING.md` 和 `docs/VERIFICATION.md`。
