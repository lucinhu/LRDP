LRDP **0.7.1 开发预览**（`v0.7.1-preview.1`，Android versionCode **11**）。

本次提供 Linux x86_64 AppImage、Android ARM64 正式签名 APK、完整源码、FFmpeg / nv-codec-headers 重建资料、构建日志和 SHA-256 校验文件。安装包从本标签提交构建；原生 ABI 保持 v5，FreeRDP 3.32.2 子模块源码未修改。

## 本次变化

- **手机默认全屏**：Android/iOS 新建连接默认全屏，桌面端仍默认窗口。设置中的“连接时全屏”按当前平台显示有效默认值；用户显式保存的 true/false 在两端都优先，不会被新默认覆盖。
- **只作用于新连接**：切换桌面标签、手机会话选择或重新打开已连接的电脑仍只切换视图，不重新套用偏好。返回连接列表会退出全屏，重新打开已连接会话保持窗口状态；手机再次新建连接仍按默认全屏。
- **设置与诊断**：设置说明改为“手机默认全屏，桌面默认窗口；切换标签不改变窗口状态”（中/繁/英同步并重新生成消息代码）；诊断信息报告当前平台解析后的有效值。
- **会话全屏与 Win 键（随 0.7.0 预览发布）**：新连接不再默认全屏，切换标签不重新进入全屏；悬浮快捷面板可直接发送 Win 键。

## 验证与限制

本地已通过 Flutter **339 passed / 11 skipped**（较 0.7.0 的 337 项新增 2 项）、`dart format` 118 个文件无变更、`flutter analyze` 无问题。本批只调整 Flutter 偏好解析、设置界面和诊断文本，未修改原生桥接、FreeRDP、协议、证书或输入代码，因此未重跑原生 CTest 与回环协议测试；上一批的 8/8 原生检查覆盖的是未变动的原生代码。组件测试使用模拟存储和平台主题，不代表真实设备验收。

发布流水线重新执行 Flutter / Python / Java host / 原生测试、签名 APK 的结构 / 主入口 / 16 KiB 校验、AppImage payload / glibc 校验和产物摘要。实际构建日志见随附的 `lrdp-0.7.1-verification.zip`。

未构建本地安装包做交互验收；Android/iOS 真机上的系统栏、导航手势、锁屏与旋转后的全屏行为仍待复验。Windows / macOS / iOS 不提供本次安装包。沿用 0.6.0 的 Android MediaCodec H.264 实验路径仍**尚未验证真实 MediaCodec Image/JNI 成功出帧**，不能承诺 CPU 或功耗下降。详细历史记录见源码内 `docs/VERIFICATION.md`。

## 安装

Android ARM64 APK 沿用正式发布密钥，可覆盖升级此前的正式签名版本。本地开发签名包与正式包签名不同；若需卸载测试包，先导出不含密码的配置并妥善保留凭据，卸载会清除应用数据。

```sh
chmod +x lrdp-0.7.1-linux-x64.AppImage
./lrdp-0.7.1-linux-x64.AppImage
sha256sum -c SHA256SUMS
```

Linux 需要 glibc ≥ 2.35 和可用的 OpenGL / EGL；无 FUSE 时可用 `APPIMAGE_EXTRACT_AND_RUN=1`。Linux 硬解需要宿主机驱动及设备权限，不支持时回退 CPU。
