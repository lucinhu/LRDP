# 使用指南

本机文字、图片和文件的传输方式见 [剪贴板与文件传输](CLIPBOARD.md)。
本机复制文字后，可在会话悬浮工具栏选择“更多 → 粘贴本机文字”。

## 外观与帧率

“设置 → 主题模式”可选“跟随系统”“浅色”“深色”。新安装默认跟随系统，
系统切换明暗时立即生效，不会断开会话或清空正在编辑的连接。
旧版本中已经手动选择的明暗外观会保留，可在这里改为跟随系统。

“使用系统配色”默认开启。Android 12 及以上采用壁纸配色，Linux、Windows、
macOS 读取系统可提供的主题色；返回应用或系统明暗变化时重新读取。
系统不提供配色（包括当前 iOS 接入）时使用 LRDP 默认配色。
桌面右上角“外观”菜单也可以切换主题模式。

实际 Android Release：[系统浅色](screenshots/android-system-theme-light.png) ·
[系统深色](screenshots/android-system-theme-dark.png)。

“画面帧率上限”默认自动跟随当前屏幕，支持 30、60、90、120、144、165、240 帧/秒。
设置的是客户端显示上限，实际不会超过屏幕刷新率；无法读取刷新率时，自动模式使用
60 帧，手动选择作为回退上限。切换设置或移动到不同刷新率的屏幕后，无需重新连接。
Android 在会话可见时向系统请求适合的刷新率，离开会话或进入后台后恢复原设置。
系统省电策略可能限制刷新率。高帧率也需要远端提供足够的更新，受网络、分辨率和解码
性能影响；低帧率服务器不会因这一选项产生额外画面。手机上可降低上限以节省电量。

## 连接远程电脑

点击“添加电脑”，填写电脑地址、用户名、密码。非默认端口可以写成
`192.168.1.10:3390`，IPv6 写成 `[2001:db8::1]:3389`。域账号的域填写在独立的
“域”字段。保存后点击连接卡片开始连接。

首次连接自签名证书时，核对服务器的 SHA-256 指纹，再选择仅本次信任或保存
指纹。服务器更换证书后会重新确认。密码只有勾选记住时才交给系统安全存储。

桌面可以同时连接多台电脑，用顶部标签切换；未激活的会话保留连接并暂停向
Flutter 传递画面。桌面全屏时，左上角提供“释放控制”和退出全屏按钮。
`Ctrl + Alt + Home` 释放远端鼠标与键盘，恢复本地鼠标并展开会话工具，画面保持刷新。
之后第一次点击远程画面只恢复控制，不会向远端发送该次点击。
`Ctrl + Alt + Enter` 切换全屏，也可在返回本地控制后使用；无需借助系统 Win 键。

编辑已有连接后点“保存并连接”，文件传输、剪贴板、分辨率、NLA、自动重连
及新输入的密码会用于新会话；只点“保存连接”保留当前连接。仅修改名称、分组、
收藏等展示配置时，再点电脑卡片可回到原会话。

## 掉线与重连

已成功连接的会话遇到可识别的网络故障后，会按 1、2、4、8、16 秒间隔重连，
最多五次。状态页显示倒计时，可点“立即重连”或“取消重连”；连接偏好中的
“掉线后自动重连”可关闭此功能。连接稳定 30 秒后才恢复完整重试次数。

手机退到后台时暂停重连倒计时，返回前台后从剩余时间继续；后台时间不重置
次数预算。健康会话继续连接，但暂停向界面传递画面。已经开始的一次重连可
完成；若后台收到需要确认的新证书，返回应用后才显示新旧指纹，不继续自动重试。
多个待确认会话逐个提示；取消后不会因为切换前后台再次弹出同一提示。

首次连接失败、密码错误、证书待确认、服务器明确注销/断开和本地主动断开都
不会触发自动重试。服务器换证书时必须重新核对指纹。取消正在进行的自动重连
也会停止该次连接；手动“重新连接”会重新开始次数预算。

重连使用当前会话内存中的凭据重新认证，不重放掉线前的按键或文字。
是否回到服务器上的原会话由服务端策略决定。完全丢包的检测时长仍取决于操作
系统和 FreeRDP 的网络超时；手机 Wi-Fi/蜂窝切换、锁屏和长时间断网需真机验收。

## 手机操作

手机使用底部“电脑 / 收藏 / 最近 / 设置”导航。连接列表可搜索、按分组筛选；
点按电脑直接连接，右侧菜单可编辑或打开中转站。右下角添加按钮打开全屏表单，
保存操作固定在底部。横屏继续使用手机布局。

会话默认全屏，悬浮工具栏可拖动、收起和重新展开；提供键盘、触控板、移动画面、
适应屏幕和更多操作。返回列表保持连接。“更多”内有动态分辨率、文件中转站、
同步剪贴板、粘贴本机文字、Ctrl+Alt+Del、Windows 键和断开操作。
动态分辨率与剪贴板按服务端协商能力启用。

返回列表或切换会话会保留各自的缩放位置、光标和操作模式，返回时键盘保持收起。
旋转、弹出键盘或远程分辨率变化后，客户端在画面边界允许的范围内保留原来查看的区域。
关闭会话后清除这次的视图状态，再次连接使用默认视图。

横屏键盘占用空间较多时，连接表单会把“保存连接”和“保存并连接”移到上方，
当前输入框仍可滚动显示；关闭键盘后恢复完整表单。

## 远程声音

在“编辑连接 → 连接偏好”开启“播放远程声音”，保存后重新连接。
默认关闭；开启后在本机播放远程电脑的声音，音量使用系统音量控制。
服务端需要允许声音重定向。本功能不启用麦克风。

## 文字输入与键盘模拟

点击悬浮工具栏“键盘”打开输入面板。新安装默认使用“键盘模拟”；切换模式后，
当前会话会记住选择，后续新建会话与应用重启也沿用最近保存的模式。

在模式菜单选择“文字输入”，使用本机输入法输入任意语言，再点击发送箭头。
“发送”会结束当前输入法组合并提交
输入栏显示的文字；输入和选词过程不会自动发送。发送后保留输入焦点，可继续输入。

“文字输入”通过 RDP Unicode 按键发送文字，不依赖剪贴板或 Ctrl+V。
发送前先点击远端要输入的位置。服务端未开放 Unicode 输入时会保留文字并提示切换方式。
若远端应用不接受直接文字输入，打开左侧模式菜单，
选择“粘贴输入”，再输入并发送；两种文字模式切换时会保留草稿，选择在当前会话中保留。

“粘贴输入”传输完整文字，等待服务端确认后发送 Ctrl+V。等待时显示进度，失败保留文字，
不会自动改用另一方式重发。它会覆盖远程剪贴板，需要连接设置启用“剪贴板”及服务端允许
CLIPRDR。协议确认表示文字和快捷键已传输，目标应用是否接受仍需观察。
不接受直接 Unicode 的应用或服务可使用“粘贴输入”。

“键盘模拟”将本机软键盘产生的字母、数字、符号及编辑键即时发送为远端按键，无需点击发送。
`a` 对应 A 键的按下与释放，`A` 对应 Shift+A；字符按美式键盘布局映射。
也可以先在远端选择需要的输入法，再发送对应字母，由远端处理选词。
无法映射为按键的文字可切换“文字输入”或“粘贴输入”，支持哪种语言取决于远端应用。
软键盘的完成/回车动作、退格文本编辑，以及键盘发出的回车、退格、方向键事件都可用于远端；
回车后保持输入焦点。如果输入法不产生方向键事件，可使用扩展按键栏中的方向键。

尚未发送的文字草稿在收起、重开键盘、切换输入模式以及临时离开当前会话时保留。
重新打开后保留文字和选区，不恢复旧输入法候选状态，也不会自动重发。
草稿仅保存在当前连接的内存中，不写入配置、导出文件或日志；关闭连接或退出应用后清除。
键盘模拟的本地按键历史不会在重开时重放。
输入框正在使用时，打开模式菜单会保持软键盘展开；外接键盘也可用 Tab、方向键和回车选择模式。
键盘模拟中的实体 Tab/Shift+Tab 会转到本地模式菜单；向远端发送 Tab 可使用特殊按键栏。
`Ctrl + Alt + Home` 在输入面板或桌面输入对话框中同样可释放控制并关闭面板。

软键盘上方可点亮 Ctrl、Shift、Alt、Win，再点一次取消；可同时选择多个键。
右侧锁图标切换“锁定模式”，默认关闭：选择修饰键后，下一次按键与它组合，随后自动释放。
例如点击 Ctrl 再输入空格发送 Ctrl+Space，接下来输入的字母不再带 Ctrl。
开启锁定模式后，修饰键持续按下，适合保持 Shift 连续选择或输入，也可与远程画面的触控操作组合。
再次点击该修饰键可释放；关闭锁定模式会立即释放所有已选修饰键。
在“键盘模拟”中，本机输入法输入的字母、数字和空格，以及扩展栏或输入法发出的编辑键
均遵循上述模式。保持 Shift 时，输入法自身产生的大写字母不会提前释放 Shift。
每次打开键盘，特殊按键栏默认只显示一排。
按键栏支持横向滑动；“展开特殊按键”的第二排优先提供 Esc、Tab、方向键、Home/End、
PgUp/PgDn、Insert/Delete、退格、回车，以及复制、粘贴、剪切、全选、撤销和重做组合键。
同排还提供 CapsLock/NumLock/ScrollLock、PrintScreen、Ctrl+Shift+Esc 与 Ctrl+Alt+Del；
F1～F12 放在该排末尾。
切换文字模式、发送整段文字、收起键盘、失去输入焦点或进入后台
会释放保持键，避免影响下一次操作；保持状态不保存到配置文件。
当前连接会记住锁定模式的选择，收起键盘或返回后仍保留；已按下的修饰键不会恢复。
新连接默认关闭锁定模式。

横屏弹出软键盘时会收起标题栏和快捷键，留出输入空间。
系统字号较大或输入法占用空间较多时，可上下滑动输入面板，查看完整提示和操作按钮。
键盘展开时，可以继续在远程画面上轻点、拖动和双指滚动，无需先收起输入法。
大字号提示较长时，可滚动键盘工具栏区域查看，远程画面仍保留手势操作区域。
“键盘模拟”不显示本地输入框，只保留键盘工具栏；用系统返回键隐藏输入法后，
点击“显示键盘”可重新打开，继续向远程电脑发送按键。

## 双向文件传输

1. 编辑连接，展开“连接偏好”，开启“文件传输”，保存并重新连接。
2. 在连接卡片菜单或会话工具栏打开“文件中转站”。未连接时也能提前放入文件。
3. 点击“放入本地文件”，选择一个或多个文件。中文文件名保留；重名会自动编号。
4. 在远程 Windows 文件资源管理器的地址栏输入 `\\tsclient\LRDP`。
5. 从此目录复制文件到远程磁盘，即为上传；把远程文件复制到此目录，即为下载。
6. 返回中转站刷新。桌面端点击文件的另存按钮；手机端点击“保存或分享”。

桌面端可在连接偏好中选择一个指定共享目录，替代应用中转站。远程电脑可读写
被共享的目录，操作会直接影响其中的文件。默认不共享任何本地磁盘。
关闭文件传输并重新连接后停止共享；本地文件保留。删除连接也不会删除中转站
中的文件；删除前可先导出需要的内容。

文件传输使用微软的 [RDP 文件系统虚拟通道协议 MS-RDPEFS](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-rdpefs/34d9de58-b2b5-40b6-b970-f82d4603bdb5)，
由未修改的 FreeRDP drive 后端处理。服务器管理员可能通过策略禁用磁盘重定向。
[MS-RDPECLIP 通道](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-rdpeclip/fb9b7e0b-6db4-41c2-b83c-f889c1ee7688)
已接入文字、双向图片及选择本机文件粘贴到远端。使用“更多 → 选择文件粘贴”前，先在远端打开
目标文件夹；服务端需协商文件流。远端文件剪贴板下载和文件夹粘贴仍待实现，反向文件传输继续使用
共享目录。详细操作和大小限制见 [剪贴板与文件传输](CLIPBOARD.md)。

## 触控与画面

手机默认触控板模式：单指滑动移动可见光标，轻点左键，双指轻点或长按后松开执行右键。
也可切为触屏模式，直接点按画面位置。双击后按住第二次触摸并移动可拖拽；
松开、手势取消、失去焦点或切到后台会释放鼠标按钮。
客户端在本地判定双击与拖拽，拖拽只发送一次按住，避免远端把标题栏拖动当成双击。
单次触屏轻点会等待约 300 毫秒完成判定，硬件鼠标不经过此等待。

双指上下或左右滑动滚动远程页面，捏合缩放画面（1–5 倍）；滚动与捏合不会发送点击。
桌面实体触控板的双指手势也可滚动和捏合，不依赖手机触控板模式；
选择“移动画面”时，双指滑动用于平移本地视野。
双指轻点只发送一次右键，取消、长时间按住或第三根手指加入不会触发右键。
触控板光标接近放大画面的边缘时，视野自动跟随，拖拽时也能继续移动到屏幕外的区域。
普通鼠标靠近可视区边缘后会持续平移，移回中间或移出会话后停止；到达远程桌面边界后停止。
画面不够宽或高的方向保持居中，横竖屏切换后重新限制画面边界。
“缩放 / 移动画面”按钮切换到单指平移，查看放大后的桌面；“更多 → 适应屏幕”恢复。
匹配分辨率需要服务端协商动态显示通道。不同厂商输入法的候选和纠错行为、实体手机手势及触觉反馈仍需真机验收。


## 远程鼠标光标

触控板模式显示服务器下发的光标图像和热点；文本选择、窗口缩放等形状随服务器
更新。普通鼠标移入远程画面时也使用此光标。单色光标的反相区域按当前桌面背景
显示；服务器可隐藏光标或恢复默认箭头。移动与点击仍以热点对应的远程像素为准，
缩放不改变点击位置。直接触控时不持续显示触控板指针。

支持缓存光标、透明像素和最大 384×384 的大光标；尺寸与能力由
[微软 RDP 大光标规范](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-rdpbcgr/41323437-c753-460e-8108-495a6fdd68a8)
及 FreeRDP 协商。客户端使用 Flutter 软件合成光标，系统原生鼠标捕获与相对输入
仍待完善。


## 声音与会话切换

在连接偏好中开启“播放远程声音”后重新连接，默认保持关闭；不会开启麦克风。
只有当前前台会话播放声音。返回电脑列表、切到其他会话或把应用放到后台时暂停，
回到原会话后继续播放新声音，无需重新连接；客户端会丢弃暂停时收到的音频。
Android 收到其他应用的临时音频焦点或降低音量请求时也暂停，重新获得焦点后继续。
系统永久收回音频焦点后，可返回电脑列表再进入会话重新申请。
