LRDP (Lightweight RDP): a lightweight, local-first RDP client built with Flutter and FreeRDP.

LRDP (Lightweight RDP) is a lightweight, local-first RDP client: Flutter provides the interface and the FreeRDP core runs embedded in the app, so no external RDP client is involved. It covers the everyday workflow: quick connect with import and export of `.rdp` profiles, groups, favorites, search, recent connections and multiple sessions; full-screen sessions with a draggable floating toolbar, trackpad or direct-touch control, two-finger scrolling, zoom and drag; and Chinese text input, simulated keys and one-shot or locked Ctrl/Shift/Alt/Win modifiers.

Clipboard integration includes text and bidirectional pictures, pasting local files to the remote, and a file transfer station for copying files both ways. Exported `.rdp` profiles, exported configuration and diagnostics never contain passwords. Passwords are kept in the system secure storage, certificate fingerprints require explicit confirmation, and session reconnects are bounded and can be cancelled. Remote audio playback is optional.

LRDP is licensed under Apache-2.0 and is available as a 0.2.0 development preview for Linux (x86_64 AppImage built on Ubuntu 22.04) and Android (ARM64 APK); Windows, macOS and iOS ports are in place but pending build and device verification. Current feature support, verification scope and known limitations are documented in the repository at https://github.com/lucinhu/LRDP (see `docs/VERIFICATION.md`), and preview builds are published at https://github.com/lucinhu/LRDP/releases/tag/v0.2.0-preview.1.
